Добавление роли

Введите название роли и права доступа

Доступные права:

• view_events - просмотр мероприятий

• edit_events - редактирование мероприятий

• delete_events - удаление мероприятий

• view_tickets - просмотр билетов

• edit_tickets - редактирование билетов

• buy_tickets - покупка билетов

• view_orders - просмотр заказов

• edit_orders - редактирование заказов

• manage_users - управление пользователями

• all - полный доступ

Укажите права через запятую (например: view_events,view_tickets)

Оставьте пустым, если права не требуются
